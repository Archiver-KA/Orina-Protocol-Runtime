All guides cover these 6 core tests:

1. **✅ Test 1: Data Isolation**
   - Verify each wallet has separate data
   - Test multi-wallet safety

2. **✅ Test 2: Auto-Migration**
   - Verify old data migrates automatically
   - Confirm one-time execution

3. **✅ Test 3: Profile Reset**
   - Verify complete data cleanup
   - Test 6-phase reset process

4. **✅ Test 4: Messaging System**
   - Test address-based messaging
   - Verify storage keys

5. **✅ Test 5: Notifications**
   - Test notification storage
   - Verify preferences saving

6. **✅ Test 6: Favorites**
   - Test favorites storage
   - Verify add/remove

### **All Tests Must Pass:**
- ✅ Storage keys contain wallet address
- ✅ Different wallets = different data
- ✅ Reset removes ALL user data
- ✅ Migration runs once per wallet
- ✅ No console errors
- ✅ Data persists after reload

### **Production Ready When:**
- ✅ All 6 tests pass
- ✅ No TypeScript errors
- ✅ No console errors
- ✅ Multi-wallet tested
- ✅ Reset verified
